# Happy Baby Style - Sitio Web

Sitio web optimizado para SEO de Happy Baby Style, marca de ropa orgánica para bebés.

## 🚀 Características SEO Implementadas

### ✅ Meta Tags Optimizados
- **Title tag**: Optimizado con palabras clave principales
- **Meta description**: Descripción atractiva de 155 caracteres
- **Keywords**: Palabras clave relevantes para el nicho
- **Canonical URL**: Evita contenido duplicado
- **Robots meta**: Control de indexación

### ✅ Open Graph y Twitter Cards
- **Open Graph**: Optimizado para Facebook y redes sociales
- **Twitter Cards**: Imagen y descripción para Twitter
- **Imágenes sociales**: Dimensiones optimizadas (1200x630px)

### ✅ Datos Estructurados (Schema.org)
- **Organization**: Información de la empresa
- **WebSite**: Datos del sitio web
- **Product**: Información de productos
- **Breadcrumbs**: Navegación estructurada

### ✅ Accesibilidad
- **Skip links**: Navegación por teclado
- **ARIA labels**: Etiquetas para lectores de pantalla
- **Roles semánticos**: Estructura HTML semántica
- **Contraste**: Colores accesibles

### ✅ Performance
- **Lazy loading**: Carga diferida de imágenes
- **Preconnect**: Conexiones optimizadas
- **Compresión**: Imágenes optimizadas
- **Minificación**: CSS y JS optimizados

## 📁 Archivos SEO

- `robots.txt` - Instrucciones para crawlers
- `sitemap.xml` - Mapa del sitio
- `site.webmanifest` - Configuración PWA
- `index.html` - Página principal optimizada

## 🔧 Configuración Necesaria

### Google Analytics
1. Reemplazar `GA_MEASUREMENT_ID` en el script de Google Analytics
2. Configurar eventos personalizados si es necesario

### Favicon
Crear los siguientes archivos en `/imgs/`:
- `favicon-32x32.png`
- `favicon-16x16.png`
- `apple-touch-icon.png`
- `icon-192x192.png`
- `icon-512x512.png`

### Imágenes Optimizadas
- Convertir imágenes a formato WebP
- Optimizar tamaños para diferentes dispositivos
- Agregar atributos `alt` descriptivos

## 📊 Métricas SEO a Monitorear

- **Core Web Vitals**: LCP, FID, CLS
- **PageSpeed Insights**: Puntuación móvil y desktop
- **Google Search Console**: Posiciones y clics
- **Analytics**: Tiempo en página, tasa de rebote
